# Para Dani 💌

Orden en que lo ve:

1. `index.html`: la carta que se abre
2. `juego.html`: ¿cuánto me conoces?
3. `final.html`: mensajes y tarjetas de cosas bonitas

## Personalizar

Todo lo personal está en **`config.js`**. No hace falta tocar nada más.

- [ ] `carta`: escríbela con tus palabras
- [ ] `preguntasJuego`: preguntas sobre ti
- [ ] `mensajes` y `cosasBonitas`: lo que quieras decirle
- [ ] (Opcional) fotos: cópialas a una carpeta `fotos/` y ponlas en `fotos`
- [ ] (Opcional) música: pon un `.mp3` en la carpeta y escribe su nombre en `musica`

## Actualizar el link

Después de editar, sube los cambios y en 1 o 2 minutos se ven en el mismo link:

```bash
git add -A && git commit -m "Actualizo textos" && git push
```
